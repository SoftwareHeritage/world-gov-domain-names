#+title: World Gov domain names

A list of government domain names used to measure government
contributions to publicly available software archived by Software
Heritage.

Coverage : 197 jurisdictions, with their UN status explicitly marked :

- *193 UN member states*
- *2 UN observer states* (Holy See, Palestine) -- to be included as
  observers, not as member states
- *2 non-UN entities* (Taiwan, Kosovo) -- included for technical
  context but *excluded from any UN-facing aggregation*

The UN status of each country lives in =data/world-governments.csv=
(column =un_status=) and is propagated as a column in the consolidated
=consolidate_domain_names_list.csv=.

* Data

** =consolidate_domain_names_list.csv= (root)

The consolidated output: every government subdomain that returned HTTP
=200= over HTTPS, with the UN status and key metadata of its country.

#+begin_example
subdomain,parent_domain,country,un_status,region,languages,gdp_per_capita
www.gouv.fr,gouv.fr,FRA_france,member,Europe,French,46103
api.moi.gov.ps,gov.ps,PSE_palestine,observer,Asia,Arabic,3464
1872.arte.gov.tw,gov.tw,TWN_taiwan,non_un,Asia,Mandarin Chinese,
#+end_example

Filter to UN member + observer states only :
=awk -F, 'NR==1 || $4!="non_un"' consolidate_domain_names_list.csv=.

** =countries/<ISO3>_<slug>/=

One directory per country (=FRA_france=, =USA_united_states=…). Each
holds exactly four entries:

#+begin_example
countries/FRA_france/
├── summary.md       -- human-readable cross-check report
├── subdomains.csv   -- all subdomains, aggregated across root domains
├── candidates.csv   -- scored domain candidates (0-10) not yet covered
└── sources/         -- raw per-source data (see below)
#+end_example

*** =subdomains.csv=

All subdomains for the country, aggregating every root domain, with
their HTTPS status:

#+begin_example
subdomain,parent_domain,http_status
www.gouv.fr,gouv.fr,"200"
ssl.gouv.fr,gouv.fr,"DNS error: ..."
foo.gouv.fr,gouv.fr,
#+end_example

The =http_status= field holds the HTTPS HEAD response code, the curl
error message, or is empty (not yet probed). Generated by the
=aggregate= phase from =sources/<root>/subdomains.csv=.

*** =candidates.csv=

Domain candidates not yet covered, scored 0-10 by cross-source
agreement (UN/DESA portal, Wikidata mentions, ccTLD match, Factbook
institution names ; minus penalties for territorial subdivisions):

#+begin_example
hostname,score,sources,label
gouvernement.fr,9,un_desa;wikidata,Council of Ministers | UN/DESA national portal
parlement.fr,8,wikidata;wikidata,French Parliament
#+end_example

*** =summary.md=

Per-country cross-check report: UN status, ccTLD, OECD membership,
EGDI rank, government type, top-20 scored candidates, ccTLD anomalies.
Generated by the =report= phase. Do not edit by hand.

*** =sources/=

Raw per-source data, isolated from the curated dataset:

- =sources/<root>/subdomains.csv= -- one directory per root domain
  (most countries have one, e.g. =gouv.fr= ; Italy has several:
  =gov.it=, =governo.it=, ministry-specific domains).
- =sources/wikidata/central_admin.csv= + =missing_domains.csv=
- =sources/iana/cctld.csv=
- =sources/cia_factbook/government.json= + =summary.csv=
- =sources/un_desa/summary.csv=
- =sources/oecd/membership.csv=
- =sources/country_data/info.csv=

⚠️ Promotion of a candidate from =sources/= or =candidates.csv= to a
real root-domain directory under =sources/<root>/= is *manual*.

*** =sources/country_data/info.csv=

Country metadata, a =field,value= CSV combining two open sources:

#+begin_example
field,value
region,Europe
subregion,Western Europe
languages,French
currencies,EUR
population,66351959
capital,Paris
gdp_per_capita,46103
gdp_year,2024
#+end_example

- =region=, =subregion=, =languages=, =currencies=, =population=,
  =capital= come from [[https://restcountries.com][REST Countries]] (keyed by ISO3).
- =gdp_per_capita= (current US$) + =gdp_year= come from the [[https://data.worldbank.org][World Bank]]
  API (indicator =NY.GDP.PCAP.CD=, most recent non-empty value).

These fields are surfaced in each country's =summary.md= (Overview
section) and propagated as the =region=, =languages= and
=gdp_per_capita= columns of =consolidate_domain_names_list.csv=.

** =data/=

- =world-governments.csv= -- master list of 197 countries
  (=Country,Region,email address domain,Government Portal Domain,URL,un_status=)
- =country_qid.csv= -- generated mapping =country_dir,iso3,wikidata_qid=
- =factbook_gec.csv=, =factbook_aliases.csv=, =un_desa_ids.csv=,
  =un_desa_aliases.csv= -- generated country-name <-> source-id mappings

** =scripts/=

The whole pipeline is a single Babashka script, =scripts/pipeline.clj=,
exposed through =bb.edn= tasks. Run =bb pipeline help= for the list of
sub-commands. See =scripts/README.org=.

* Sources

This dataset is built from multiple sources, layered from broad
harvest to authoritative enrichment. All enrichment sources are
*isolated* under =countries/<c>/sources/<source>/= ; promotion of any
candidate to a root-domain directory is *manual*.

** In use

- crt.sh  :: Primary harvest of subdomains observed in publicly issued
  certificates.
- HTTPS HEAD probes :: verification that a subdomain actually serves
  content (status =200=).
- Wikidata :: enrichment with central administration bodies
  (ministries, parliaments, central banks, supreme/constitutional
  courts) and their official websites.

** International official sources for cross-validation

Scope: *central administrations and independent authorities attached to
central government only*. For now, we exclude local and regional
authorities, universities, hospitals, etc.

- IANA Root Zone Database :: authoritative registry of ccTLDs;
  identifies the sponsoring organisation of each country's top-level
  domain.
- UN/DESA Public Administration :: UN E-Government Knowledgebase:
  per-country National Portal URL and EGDI ranking.
- CIA World Factbook (via [[https://github.com/factbook/factbook.json][factbook.json]] mirror) :: structured
  government section per country (executive / legislative / judicial
  branches). Note: the original Factbook was wiped by the CIA in
  February 2026 ; we use a community JSON mirror.
- OECD Government at a Glance :: flags OECD membership and links to
  the relevant SDMX dataset for governance indicators.

* Running the pipeline

The pipeline is a single [[https://babashka.org][Babashka]] script, =scripts/pipeline.clj=,
exposed through =bb.edn= tasks.

** Install Babashka

#+begin_src bash
# Linux / macOS (official installer)
bash <(curl -s https://raw.githubusercontent.com/babashka/babashka/master/install)

# or with Homebrew (macOS / Linux)
brew install borkdude/brew/babashka
#+end_src

=curl= is also required (=babashka.curl= shells out to it).

** Run

From the repository root:

#+begin_src bash
  bb pipeline help          # list all sub-commands

  bb pipeline enrich        # wikidata + iana/cia/un-desa/oecd/meta (parallel)
  bb pipeline report        # generate candidates.csv + summary.md per country
  bb pipeline collect       # crt.sh harvest -> probe -> consolidate_domain_names_list.csv
  bb pipeline all           # collect + enrich + report

  # Targeted runs, optionally scoped to specific countries:
  bb pipeline report FRA_france DEU_germany
  FORCE=1 bb pipeline enrich     # force re-fetch of existing outputs
#+end_src

See =scripts/README.org= for the full command reference, scoring rules,
and environment variables.
