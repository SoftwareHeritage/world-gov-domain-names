#+title: World Gov domain names

This repository collects the government domain names of 197 States and
entities, so we can measure how much governments contribute to
publicly available software archived by Software Heritage.

* Coverage

197 jurisdictions, each tagged with its UN status:

- *193 UN member states*
- *2 UN observer states*: Holy See, Palestine
- *2 non-UN entities*: Taiwan, Kosovo (kept for context, but excluded
  from any UN-facing aggregation).

* What you get

The repository is organised around a few outputs.

** Consolidated lists (repo root)

Two ready-to-use CSV files, covering UN members and observers only:

- =public-sector.csv= -- every government host we found, apex domains
  *and* subdomains (e.g. =www.gouv.fr=, =beta.gouv.fr=).
- =public-sector-central-gov.csv= -- one row per central-government
  *root domain* (e.g. =gouv.fr=, =insee.fr=). A root already stands for
  all its subdomains, so this is the short list of email domains to
  watch.

Each row also carries country metadata: UN status, region, languages
and GDP per capita.

** Per-country data (=countries/<ISO3>_<slug>/=)

One directory per country (=FRA_france=, =USA_united_states=, …), with:

- =subdomains.csv= -- all known subdomains and their HTTP status,
- =candidates.csv= -- domains we spotted but haven't confirmed yet,
  scored 0--10 by how many sources agree,
- =summary.md= -- a human-readable cross-check report,
- =sources/= -- the raw data behind the above, one folder per source.

** Master data (=data/=)

- =world-governments.csv= -- the master list of the 197 countries
  (name, region, portal, UN status, ISO codes, income group).
- A few generated mapping files linking country names to source IDs.

* Where the data comes from

The dataset is layered, from a broad harvest to authoritative
enrichment:

- *crt.sh* -- subdomains seen in public TLS certificates (main harvest).
- *HTTPS probes* -- check that a host actually serves content.
- *Wikidata* -- ministries, parliaments, central banks, courts and
  their official websites.
- *IANA, UN/DESA, CIA World Factbook, OECD* -- official sources used to
  cross-check candidates.

Scope is *central government only* for now: local and regional
authorities, universities and hospitals are left out. Promoting a
candidate to a confirmed root domain is always a *manual* decision.

* Running the pipeline

Everything is driven by Babashka through =bb.edn= tasks.

#+begin_src bash
# Install Babashka (Linux / macOS)
bash <(curl -s https://raw.githubusercontent.com/babashka/babashka/master/install)

# From the repository root:
bb pipeline help     # list all sub-commands
bb pipeline all      # full run: collect + enrich + report
#+end_src

See =scripts/README.org= for the full command reference, scoring rules
and environment variables.
