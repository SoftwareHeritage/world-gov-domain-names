This file is for LLM-based agents working in this repository.

# What you must never do

- **Do not act on the project by yourself.** Never open issues or work
  items, push commits, create or merge merge requests, post comments
  or reviews, or send emails. Prepare the material locally and let the
  human do these actions.
- **Do not add Co-authored-by:, Assisted-by: or any other trailer
  mentioning LLM assistance**.

# What you may do

- Translate or rephrase text written by a human.
- Propose diagnoses and contents that a human can review.

# How to work

- **Every change should relate to an existing work item.** If the
  human has not mentioned one, ask which work item the change
  addresses. Merge requests must refer to a work item, and a merge
  request that closes one says `Closes #N`.
